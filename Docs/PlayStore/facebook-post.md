# Facebook post: Android testers for JS8 Firefly

## Task

Post the message below, once each, in the amateur radio Facebook groups you already
have access to. Post as Nathan (NR5P).

- Best fits: JS8Call, digital modes, QRP, portable/POTA/SOTA, QRP Labs (QMX/QDX),
  Digirig and Android ham radio groups. Skip groups that aren't about amateur radio.
- Read each group's rules first. Skip any group that bans self-promotion or app posts,
  or that requires admin approval you can't get; list those instead of posting.
- Use the text exactly as written. Facebook does not render markdown, so paste it as
  plain text. Keep both links and keep them in this order.
- Attach the image `Docs/PlayStore/graphics/feature-graphic.png` if the group allows images.
- One post per group. Do not repost, cross-comment or message members.
- When done, report which groups you posted in (with a link to each post), which you
  skipped and why.

## Post text

Need 12 Android testers for JS8 Firefly, a free open-source JS8 app

I'm Nathan, NR5P. I wrote JS8 Firefly, a JS8 client for Android phones and tablets. It works with JS8Call stations on all five speeds, and it's open source with no ads, accounts or tracking.

Google won't let a new developer release an app until 12 people have been opted in to a closed test for 14 days straight, so I need your help to get it into the Play Store.

If you have an Android device, it's two steps with the same Google account:

1. Join the tester group (sign in, then Join group):
https://groups.google.com/g/js8firefly-testers/about

2. Opt in and install from Google Play:
https://play.google.com/apps/testing/com.js8firefly.app

You don't need a radio connected to help; anyone can install it and listen. If you have a Digirig, QMX or QDX, on-air reports are very welcome. Please stay opted in for two weeks.

Source code: https://github.com/NR5P/js8-firefly-android

Thanks and 73, NR5P

## If someone asks

- Cost: free during the test.
- "The group link says I don't have permission": use the link ending in /about, sign in
  to Google, then click Join group.
- "The Play link says app not found": join the group first, use the same Google account
  for both steps, and try again a little later.
- iPhone: there is already an iPhone version; see https://nr5p.com/js8-firefly.html
- Anything else: don't guess. Tell them Nathan will reply, and include the question in
  your report.
